# Current research status

Status date: 2026-08-16.

## Decision

**NO-GO for the core learned on-demand context controller.**

The current evidence supports narrower mechanism-level claims, but it does not yet show that a learned agent can decide what context to acquire and when to stop better than a strong static policy.

## Why the controller remains a NO-GO

### Tau2 selective controller

The original held-out Tau2 controller was not changed by the later studies. Full context reaches 34.2% safe selected actions over 380 prefixes. The risk-controlled selective policy reaches 13.8% safety when attempted at 51.3% coverage. Its own study therefore remains a NO-GO.

### OpenRCA source selection

The supervised metric-plus-trace action model reaches 84.3% top-3 component accuracy, showing that the modalities contain useful triage signal. However, the learned two-source router has the same action accuracy as the static metric-plus-trace policy in every tested condition. Its lower synthetic cost comes mainly from selecting an exact metric duplicate assigned a lower price. This does not establish a meaningful adaptive advantage.

The earlier 27.5% and later 84.3% OpenRCA top-3 results are different model formulations:

- 27.5%: unsupervised fixed anomaly heuristic;
- 84.3%: supervised leave-one-date-out candidate ranker with historical priors and richer features.

They must not be presented as results from the same model.

## What is supported

- Metric and trace evidence contains useful OpenRCA component-triage signal.
- Current, complete telemetry outperforms stale and partial windows in the tested replay.
- Explicit entity ownership constraints prevent tested wrong-asset actions.
- Explicit source authority prevents tested prediction-overtrust failures.
- Controlled user/system probing can reduce synthetic interaction cost.
- Archived LLM behavior is not a reliable standalone context-sufficiency gate.

These are supporting or controlled-intervention results. They do not override the controller NO-GO.

## Required next proof

A future controller study must:

1. exclude artificial duplicate sources;
2. train source value and action safety as separate decision-level objectives;
3. calibrate on trajectories generated by the deployed acquisition policy;
4. compare against cost-matched static, per-level, and fixed-relevant policies;
5. improve action reliability or preserve it with a material real cost reduction; and
6. make canonical metrics reproducible from pinned inputs.

Until those conditions pass, the project should describe adaptive context gathering as an open hypothesis.
