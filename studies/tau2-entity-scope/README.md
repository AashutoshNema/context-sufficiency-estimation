# Study: Tau2 entity scope

## Question

Do explicit entity ownership and scope constraints prevent an agent from acting on the wrong asset?

## Status

**Positive controlled replay.** The entity-aware model eliminates wrong-asset actions in the tested intervention suite while improving aggregate safe-action rate over the mechanical model.

This does not establish behavior on large causal graphs or natural cross-document coreference.
